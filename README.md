# وایب‌بورد (Vaib-Board)

یک شبکه اجتماعی فارسی برای اشتراک‌گذاری تجربیات کتابخوانی و تماشای فیلم

## ویژگی‌های جدید ✨

### کتابخانه شخصی 📚
- **افزودن کتاب/فیلم/سریال**: کاربران می‌توانند آیتم‌های مختلف را به کتابخانه شخصی خود اضافه کنند
- **وضعیت‌های مختلف**: 
  - می‌خواهم بخوانم/ببینم (آبی)
  - در حال خواندن/تماشا (زرد) 
  - خوانده/دیده شده (سبز)
- **امتیازدهی**: امتیاز ۱ تا ۵ ستاره برای آیتم‌های تمام شده
- **یادداشت شخصی**: افزودن نظرات و یادداشت‌های شخصی
- **عکس جلد**: قابلیت افزودن تصویر جلد کتاب/فیلم
- **فیلتربندی**: نمایش آیتم‌ها بر اساس وضعیت
- **ویرایش و حذف**: امکان ویرایش و حذف آیتم‌ها

### ویژگی‌های اصلی موجود
- ارسال پست درباره کتاب‌ها و فیلم‌ها
- لایک و کامنت
- مدیریت پروفایل کاربری
- آپلود عکس پروفایل
- سیستم احراز هویت

## تکنولوژی‌های استفاده شده
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Firebase (Firestore, Authentication, Storage)
- **UI**: Material Icons, Vazirmatn Font
- **PWA Ready**: طراحی موبایل محور

## نحوه استفاده

### کتابخانه شخصی
1. وارد حساب کاربری خود شوید
2. به صفحه پروفایل بروید
3. روی دکمه "افزودن به کتابخانه" کلیک کنید
4. اطلاعات کتاب/فیلم را وارد کنید:
   - نوع (کتاب/فیلم/سریال)
   - عنوان
   - نویسنده/کارگردان
   - وضعیت فعلی
   - امتیاز (اختیاری)
   - یادداشت شخصی (اختیاری)
   - عکس جلد (اختیاری)
5. آیتم را ذخیره کنید

### فیلتربندی آیتم‌ها
- **همه**: نمایش تمام آیتم‌های کتابخانه
- **خوانده/دیده شده**: آیتم‌های تمام شده
- **در حال خواندن/تماشا**: آیتم‌های در حال مطالعه
- **می‌خواهم ببینم**: لیست خواندنی/دیدنی

### ویرایش آیتم‌ها
- روی آیکون ویرایش در کنار هر آیتم کلیک کنید
- تغییرات مورد نظر را اعمال کنید
- تغییرات را ذخیره کنید

## اجرای پروژه
```bash
# راه‌اندازی سرور محلی
python3 -m http.server 8000

# یا با Node.js
npx serve .
```

## ساختار دیتابیس Firebase

### مجموعه `library`
```javascript
{
  id: "document_id",
  type: "book|movie|series",
  title: "عنوان",
  author: "نویسنده/کارگردان", 
  status: "want|reading|completed",
  rating: 1-5 (اختیاری),
  notes: "یادداشت شخصی",
  coverURL: "base64_image_data",
  userId: "user_uid",
  username: "نام کاربر",
  timestamp: "firestore_timestamp"
}
```

## امنیت و دسترسی‌ها
- هر کاربر فقط به کتابخانه شخصی خود دسترسی دارد
- آیتم‌ها در مجموعه `library` بر اساس `userId` فیلتر می‌شوند
- عکس‌ها به صورت base64 ذخیره می‌شوند (بدون نیاز به Firebase Storage اضافی)

## نکات فنی
- تصاویر به صورت خودکار فشرده و تغییر اندازه می‌یابند
- رابط کاربری responsive و موبایل محور
- Real-time updates با Firebase listeners
- کش محلی برای بهبود عملکرد
